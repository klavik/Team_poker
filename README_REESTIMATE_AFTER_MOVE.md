# Team_poker — перенесённые задачи отправляются на переоценку

## Новое поведение

После успешного переноса задача в целевой сессии:

- получает статус `pending`;
- помечается `reestimateRequired=true`;
- отображается как «↻ На переоценку»;
- появляется среди активных задач;
- доступна для нового голосования;
- сохраняет прежнюю оценку в `previousEstimate`;
- начинает новый раунд, если ранее уже были голоса или итоговая оценка.

Старая итоговая оценка больше не считается актуальной.

После фиксации новой оценки отметка переоценки автоматически снимается,
а `estimateVersion` увеличивается обычным способом.

## Передача в Team_calculator

Team_poker отправляет событие схемы 3:

```text
eventType=reestimate_required
```

Событие может передаваться без `finalEstimate`, поскольку новой оценки
ещё нет.
