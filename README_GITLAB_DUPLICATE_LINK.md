# Team_poker — ссылка на предыдущее упоминание

Отметка повторной GitLab-ссылки теперь является ссылкой:

```text
Была ранее ↗
Была ранее · 3 ↗
```

## Поведение

При нажатии приложение открывает самое последнее предыдущее упоминание:

- переключает сессию;
- выбирает соответствующую задачу;
- обновляет прямую ссылку в адресной строке.

При нескольких совпадениях число показывает общее количество найденных
предыдущих упоминаний. Подсказка по наведению содержит перечень сессий,
задач и сохранённых оценок.

Ссылку можно открыть обычным нажатием либо в новой вкладке стандартными
средствами браузера.

## Установка

Заменить:

```text
app.js
styles.css
```

Firestore Rules и структура данных не меняются.

После публикации:

```text
Cmd + Shift + R
```
