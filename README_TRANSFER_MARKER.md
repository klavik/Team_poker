# Team_poker — пометка перенесённых задач

## Что изменилось

После переноса задача получает заметную пометку **«↪ Перенесена»**:

- в списке задач Team_poker;
- в карточке задачи, с названием исходной сессии, датой и автором переноса;
- в данных, отправляемых в общий пул Team_calculator.

Для передачи добавляется объект `transfer` и версия схемы интеграции `2`.
Синхронизация учитывает новую версию схемы, поэтому ранее перенесённая и уже
оценённая задача будет повторно передана при её открытии без изменения оценки.

## Обновление Team_poker

Замените четыре файла:

```text
app.js
index.html
styles.css
calculator-integration-status.js
```

`firestore.rules` менять не требуется.

После публикации выполните:

```text
Cmd + Shift + R
```

## Team_calculator

Чтобы пометка появилась в общем пуле, дополнительно обновите Worker и
`team_calculator/index.html` с помощью комплекта
`team_calculator_transfer_marker_patch.zip`.
