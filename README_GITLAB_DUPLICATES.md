# Team_poker — подсветка повторных GitLab-ссылок

## Поведение

При открытии сессии приложение один раз читает задачи остальных сессий
текущей команды.

Если GitLab-ссылка задачи уже встречалась в более ранней задаче другой
сессии, в списке задач отображается:

```text
Была ранее
```

Для нескольких предыдущих совпадений показывается количество:

```text
Была ранее · 2
```

Карточка дополнительно выделяется жёлтым фоном и полосой слева. При
наведении на отметку отображаются сессии, названия задач и сохранённые
оценки.

## Сравнение ссылок

При сравнении игнорируются:

- регистр имени сервера;
- завершающий `/`;
- query-параметры;
- фрагмент после `#`.

Например, эти ссылки считаются одинаковыми:

```text
https://git.example/group/project/-/issues/22
https://git.example/group/project/-/issues/22/
https://git.example/group/project/-/issues/22?from=email
```

## Нагрузка на Firestore

Постоянного опроса нет. История читается только при открытии сессии, а
затем хранится в памяти страницы. Повторное переключение между уже
прочитанными сессиями не вызывает повторного чтения.

## Установка

Заменить:

```text
app.js
styles.css
```

Изменения Firestore Rules и структуры документов не требуются.

После публикации выполнить:

```text
Cmd + Shift + R
```
