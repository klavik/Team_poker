# Team_poker — единый массовый выбор + исправление «Обновить статусы»

- Удалена пользовательская кнопка «Синхронизировать»: она только перезапускала Firestore network и не синхронизировала GitLab/Team_calculator.
- Чекбоксы массового выбора доступны в основном списке для активных и оценённых задач.
- Общая панель: «Выбрать все видимые» / «Начать голосование» / «Перенести» / «Снять выбор».
- «Начать голосование» действует только на выбранные pending-задачи.
- «Перенести» открывает компактный диалог без повторного списка задач.
- Режимы: «С переоценкой» и «Сохранить последнюю оценку».
- В режиме сохранения оценки задачи без истории оценки заранее показываются и исключаются.
- После массового переноса пользователь остаётся в исходной сессии.
- Firestore Rule для delivery_status_refresh теперь авторизует запрос по членству в команде + request.auth.uid; хрупкое буквальное сравнение email удалено.

Деплой: index.html, app.js, styles.css, firestore.rules. Firestore Rules обязательно опубликовать. metadata_connector v1.4.8, calculator-integration-status.js и Team_calculator не менялись.
