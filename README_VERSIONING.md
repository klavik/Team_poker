# Team_poker — versioning

Текущая версия: **v1.2.0**

Версия отображается рядом с названием Team_poker и в заголовке вкладки.

Используется Semantic Versioning:

- `v1.0.x` — исправления;
- `v1.x.0` — новые возможности;
- `v2.0.0` — несовместимые изменения.

## v1.2.0

Добавлена ручная кнопка `Передать повторно` для GitLab и Team_calculator. Повтор использует текущую зафиксированную `estimateVersion` и не создаёт новую версию оценки.

## v1.1.0

Отображаемое название приложения изменено с `Planning Poker` на `Team_poker`.
