# Team_poker — versioning

Текущая версия: **v1.0.1**

Версия отображается рядом с названием Planning Poker и в заголовке вкладки.

Используется Semantic Versioning:

- `v1.0.x` — исправления;
- `v1.x.0` — новые возможности;
- `v2.0.0` — несовместимые изменения.

## v1.0.1

Patch-релиз: добавлено отображение версии без изменения `app.js`.
Логика Firebase/Firestore и загрузки данных оставлена идентичной предыдущему
рабочему релизу.
