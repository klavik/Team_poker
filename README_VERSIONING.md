# Team_poker — versioning

Текущая версия: **v1.0.0**

## Правила

Используется Semantic Versioning:

- `MAJOR` — несовместимые изменения;
- `MINOR` — новые возможности без нарушения существующего поведения;
- `PATCH` — исправления ошибок и небольшие изменения.

Формат:
`vMAJOR.MINOR.PATCH`

Версия отображается:
- рядом с заголовком `Planning Poker`;
- в `<title>` страницы;
- в console при запуске приложения.

Следующий релиз должен увеличивать номер версии относительно
текущего релиза, а в README релиза фиксировать основные изменения.

## v1.0.0

Первый формализованный релиз с версионированием Team_poker.
Включает актуальную логику явной передачи зафиксированной оценки
в общий пул Team_calculator без автоматической отправки при открытии
карточки.
