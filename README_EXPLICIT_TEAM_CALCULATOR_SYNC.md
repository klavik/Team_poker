# Team_poker — explicit Team_calculator sync

Дата: 2026-08-10

## Что изменено

Убрана автоматическая отправка оценки в Team_calculator:

- больше нет polling `checkAndSync()` каждые 1,2 секунды;
- открытие/выбор карточки задачи не запускает отправку;
- изменение hash/перерисовка интерфейса не запускает отправку;
- обработчик `finalizeBtn` внутри модуля интеграции больше не инициирует скрытую отправку.

## Когда происходит передача

Передача выполняется явно:

1. пользователь нажимает `Зафиксировать`;
2. Team_poker сохраняет итоговую оценку;
3. после успешного commit Team_poker получает сохранённую задачу;
4. вызывается `TeamCalculatorIntegration.syncPayload(payload)`;
5. Team_calculator получает именно зафиксированную оценку.

Отдельно сохранена явная синхронизация для сценария массового переноса задачи, где она уже вызывается кодом переноса.

## Статусы

Realtime-обновление статусов доставки из Firestore не отключалось.

Сообщение `Оценка передаётся...` теперь появляется только во время реального вызова `syncPayload()`.

## Проверка

Проверены синтаксис `app.js` и `calculator-integration-status.js` через `node --check`.
