# Team_poker — отдельная колонка задач

Обновление собрано поверх актуальной версии Team_poker с:

- ролями;
- назначением направления;
- Team_calculator;
- GitLab-коннектором;
- исправленной инициализацией Firestore;
- исправленным добавлением участников.

## Что изменено

### Отдельная колонка задач

На широком экране интерфейс разделён на три части:

```text
Команда и сессия | Задачи | Карточка задачи
```

Список задач имеет собственный вертикальный скролл. Заголовок, кнопка
«Журнал» и кнопка добавления остаются видимыми.

### Группировка

Задачи разделены на:

```text
Активные
Оценённые
```

Все задачи со статусами `pending`, `voting` и `revealed` находятся выше
задач со статусом `estimated`.

### Новая задача

После добавления:

1. задача помещается первой в активную группу;
2. автоматически становится выбранной;
3. список прокручивается к ней;
4. задача кратко подсвечивается;
5. URL страницы обновляется прямой ссылкой на неё.

## Что не изменено

Не менялись:

- Firestore Rules;
- структура документов;
- голоса и раунды;
- Team_calculator;
- GitLab-очередь и Mac-коннектор;
- права ролей.

## Установка

Для точечной установки замените:

```text
app.js
index.html
styles.css
```

`firestore.rules` публиковать повторно не требуется.

После загрузки в GitHub Pages:

```text
Cmd + Shift + R
```
