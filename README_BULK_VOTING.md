# Team_poker — массовый запуск голосования

## Что изменено

У задач со статусом «Не начата» в списке появился чекбокс.

Для администратора и тимлида над списком отображается панель:

```text
Выбрать все | Выбрано: N из M
Начать голосование · N
```

## Поведение

- выбирать можно только задачи со статусом `pending`;
- задачи с уже активным голосованием, раскрытыми оценками и итоговой
  оценкой недоступны для выбора;
- «Выбрать все» отмечает все доступные задачи текущей сессии;
- после полного выбора кнопка меняется на «Снять выбор»;
- «Начать голосование» переводит все выбранные задачи в статус `voting`;
- выбор очищается при смене команды или сессии;
- если статус задачи изменился в другой вкладке, она автоматически
  исключается из выбора.

Операция использует Firestore batch. Для очень больших списков задачи
обрабатываются частями по 400 записей.

## Права

Массовая операция доступна тем же ролям, которые уже могли вручную
запускать голосование:

```text
admin
lead
```

## Установка

Заменить:

```text
app.js
index.html
styles.css
```

Firestore Rules и структура документов не меняются.

После публикации:

```text
Cmd + Shift + R
```
