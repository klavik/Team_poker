# Team_poker v1.2.0

Добавлена ручная повторная передача текущей зафиксированной оценки без создания новой версии оценки.

## Поведение

После фиксации оценки Администратор и Тимлид видят кнопку `Передать повторно` рядом со статусом каждой интеграции:

- GitLab;
- Team_calculator.

Кнопка доступна как после ошибки, так и после успешной передачи.

Повторная передача:

- не меняет `finalEstimate`;
- не меняет `estimateVersion`;
- не создаёт новый раунд голосования;
- не изменяет историю оценки;
- повторно запускает только выбранный канал доставки.

Пока job находится в `pending` или `processing`, кнопка отображается disabled, чтобы не создавать параллельные повторные отправки.

Если job по текущей зафиксированной оценке отсутствует, кнопка создаёт его заново из текущего состояния карточки.

## Firestore Rules

Разрешён только строго ограниченный переход завершённого job (`failed` или `succeeded`) обратно в `pending` для Администратора/Тимлида. Immutable-поля оценки и payload менять нельзя.

Connector Team_calculator v1.4.10 и GitLab Mac connector менять не требуется.
