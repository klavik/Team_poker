# Team_poker — task list render fix v2

Точная причина fallback-сообщения найдена.

Во время предыдущей переработки массового переноса были случайно
удалены определения:

- `issueTransferInfo()`
- `issueTransferTooltip()`

При этом основной renderer продолжал вызывать их для карточек задач.
Поэтому `renderIssues()` завершался `ReferenceError`, после чего
включался аварийный fallback и показывал сообщение:

`Задачи загружены, но часть дополнительных элементов интерфейса
временно не отрисовалась. Основной список доступен.`

В этом исправлении обе функции восстановлены в их актуальной версии
с поддержкой context целевой сессии.

Аварийный fallback сохранён как защита, но при штатной работе больше
не используется.

Для деплоя достаточно заменить:

- `app.js`

Firestore Rules, connector и Team_calculator не менялись.
