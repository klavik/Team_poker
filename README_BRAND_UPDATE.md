# Team_poker — логотип и favicon

Добавлен единый знак масти «Пики»:

- рядом с заголовком Planning Poker;
- в качестве favicon вкладки браузера.

Оба элемента используют один файл:

```text
favicon-spade.svg
```

## Установка

Заменить:

```text
index.html
styles.css
```

И добавить:

```text
favicon-spade.svg
```

После публикации выполнить жёсткое обновление:

```text
Cmd + Shift + R
```

Favicon браузер может кэшировать отдельно. Если старый значок остаётся,
закройте вкладку и откройте сайт заново.
