# Team_poker — исправление прав переноса

## Причина ошибки

Кнопка «Перенести» теперь вызывает функцию переноса, но опубликованные
Firestore Rules могут быть старее клиентского приложения.

Перенос использует дополнительные операции:

- создание временной копии задачи с `moveState=copying`;
- копирование `votes`, `vote_status` и `rounds`;
- создание записи в `issue_redirects`;
- создание событий `moved_out` и `moved_in` в `issue_audit`;
- удаление исходной задачи после проверки копии.

Все эти операции уже разрешены в приложенном `firestore.rules`.

## Обязательное обновление

Опубликовать:

```text
firestore.rules
```

Через Firebase CLI:

```bash
firebase deploy --only firestore:rules --project team-poker-6c06f
```

Либо открыть:

```text
Firebase Console → Firestore Database → Rules
```

вставить содержимое файла и нажать Publish.

## Клиентское улучшение

Обновлённый `app.js` показывает этап, на котором Rules отклонили перенос,
например:

```text
Firestore отклонил операцию на этапе «создание копии задачи».
```

Исходная задача при ошибке не удаляется.

## Установка

Обязательно опубликовать `firestore.rules`.

Рекомендуется также заменить:

```text
app.js
```

После публикации сайта:

```text
Cmd + Shift + R
```
