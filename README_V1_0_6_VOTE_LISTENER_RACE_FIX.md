# Team_poker v1.0.6

Исправлена периодическая ошибка `permission-denied` при открытии карточек,
после которой раскрытые оценки могли оставаться пустыми до перезагрузки.

Причина — две гонки realtime listeners:

1. После локального изменения `status/currentRound` Firestore сначала
   отдаёт optimistic snapshot (`hasPendingWrites=true`). Клиент уже запускал
   запросы к раскрытым/историческим голосам, тогда как серверные Rules ещё
   могли видеть старое состояние задачи и отклоняли запрос.
2. После быстрого переключения карточек callback уже отменённого listener
   старой карточки иногда мог прийти позднее и затронуть состояние новой.

Исправление:

- metadata `hasPendingWrites` сохраняется для текущей задачи;
- permission-sensitive vote listeners запускаются только после server ACK;
- переход `local -> server` включён в subscription key и автоматически
  перезапускает listeners после подтверждения записи;
- все callbacks/errors vote listeners проверяют, что относятся к текущей
  карточке;
- исторические голоса также защищены от stale callbacks.

Firestore Rules не менялись. Тимлид по-прежнему не может читать чужие
голоса во время активного голосования.

Для деплоя достаточно заменить:
- `app.js`
- `index.html`
